# Roadmap da fase acadêmica

## Etapa 1 — Fundamentação

- revisão de literatura;
- reconstrução histórica da Expansão Fase II;
- documentação das regras institucionais de seleção e implantação.

## Etapa 2 — Identificação

- elaborar DAG;
- definir estimando;
- definir outcome primário e secundários;
- formalizar população causal;
- formalizar timing;
- definir antecipação;
- definir spillovers;
- definir grupo de comparação.

## Etapa 3 — Dados

- reconstruir fontes oficiais necessárias;
- validar timing externamente;
- criar pipeline reproduzível;
- documentar provenance dos dados.

## Etapa 4 — Análise

- análise descritiva;
- balanceamento;
- event study;
- staggered DiD;
- inferência;
- robustez;
- sensibilidade;
- heterogeneidade.

## Etapa 5 — Redação

- resultados;
- validade interna;
- validade externa;
- limitações;
- discussão;
- conclusão.
